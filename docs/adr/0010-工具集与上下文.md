# 0010 Agent 工具集与运行上下文

- 状态：已接受
- 日期：2026-11-02

## 背景

0005 决定 Agent 按 Task Skill 自行完成全部步骤，工具需要通用，不能为 ingest 量身定制。Vault 数据（2026-11-02）：

- 86 份 Source，正文中位数约 1.3 万字符，P90 约 3.5 万，最大约 5.9 万。
- `log.md` 约 8.1 万字符，`index.md` 约 3.4 万字符，`wiki/` 共 420 页、约 128 万字符。

## 决策

**工具集**（读工具读取的都是 Vault 叠加 Staging 后的视图）：

| 工具                                               | 说明                                                                          |
| -------------------------------------------------- | ----------------------------------------------------------------------------- |
| `read_file(path, offset?, limit?)`                 | 按行分段读取，大文件截断并提示继续读取的位置                                  |
| `glob(pattern)`                                    | 列出匹配路径                                                                  |
| `grep(pattern, path?)`                             | 搜索内容，返回路径和命中行，结果数量有上限                                    |
| `write_file(path, content)`                        | 整文件新建或覆盖                                                              |
| `edit_file(path, old, new)`                        | 替换唯一匹配的字符串；0 处或多处匹配都报错                                    |
| `append_file(path, text)`                          | 在文件末尾追加。为 `log.md` 这类大文件准备，避免为了追加一条记录重写 8 万字符 |
| `read_skill(name)` / `read_skill_file(name, path)` | 0004 的渐进加载                                                               |
| `finish(summary)`                                  | 0007 的结束协议                                                               |

- 读取范围是整个 Vault，排除以 `.` 开头的目录（`.git`、`.obsidian`、`.agents` 等）；Skill 只能通过 Skill 工具读取。
- 没有 shell、网络、删除、移动。

**运行上下文**：

- 当前日期、时间和时区由代码注入 system prompt（Skill 要求写 `YYYY-MM-DD` 和 `HH:MM`，模型自己并不知道当前时间）。时区默认取系统时区，可在配置中覆盖。
- 目标 Source 路径由命令行参数传入，写进第一条用户消息。

**长文**：v1 不分块，`read_file` 允许分段读取。Source 超过配置的上限（默认 20 万字符）时，运行直接拒绝。

## 影响

- 工具与 Task Skill 无关，换 Task Skill 时不需要新增工具。
- `index.md` 的按字母序插入靠 `edit_file` 匹配相邻行来完成，容易出错，需要用 Warning 或评测来观察实际效果。
