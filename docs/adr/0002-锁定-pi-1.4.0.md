# 0002 锁定 Pi 1.4.0 精确版本

- 状态：已接受
- 日期：2026-11-02

## 背景

Pi 两个月内从 0.84 发布到 1.4.0，中间多次不兼容：0.86 起 system prompt 改为 transcript 中的 system message；0.87 删除 `shouldStopAfterTurn`，改用 `finishTurn`；1.0 把 harness、session、compaction 移出 `pi-agent-core`。main 分支还有未发布的改动：`pi-ai` 不再导出 TypeBox 的 `Type`。

参考项目（Torrent Vibe 0.84.2、Kansoku 0.85.x、Mix Space 0.99.1）都不在 1.x 上，它们的代码不能直接照搬。

## 决策

`@earendil-works/pi-agent-core` 与 `@earendil-works/pi-ai` 锁定精确版本 `1.4.0`，不使用 `^` 范围。

工具参数 Schema 集中定义在一个模块里，将来 `Type` 导出被移除时只需修改这一处。

`@innei/message-engine`（peer 依赖只声明 `^0.84.1 || ^0.99.0`）和 `@earendil-works/pi-durable`（Experimental）不进入 v1。

## 影响

- 升级 Pi 必须是一次单独变更，并跑通 faux 测试。
- 稳定上下文直接使用 Pi 原生能力：system `sections`、`transformContext`、`prepareRequest`。
