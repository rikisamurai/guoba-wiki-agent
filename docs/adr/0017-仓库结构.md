# 0017 仓库结构：3 个包 + 2 个应用

- 状态：已接受
- 日期：2026-11-02

## 决策

pnpm monorepo，依赖方向只能自上而下：

```text
apps/cli ──► packages/agent ──► packages/vault
   │               │
   │               └──► packages/trajectory
   └──► packages/trajectory ◄── apps/viewer
```

| 位置                  | 职责                                                                                                                  | 依赖 Pi |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- | ------- |
| `packages/vault`      | 读写 Vault、Staging 叠加视图、wikilink 与 frontmatter 解析、Write Scope、Invariant 与 Warning 校验、hash 核对与 Apply | 否      |
| `packages/trajectory` | Trajectory Event 类型、JSONL 读写、按 Turn/Step 的投影（耗时、TTFT、费用汇总）。Run 进程和查看器共用这一份契约        | 否      |
| `packages/agent`      | Pi Agent 装配、工具、Skill 加载（0004）、Finish 回路（0007）、上限（0012）、把 Pi 事件翻译为 Trajectory Event         | 是      |
| `apps/cli`            | `wiki-agent run`（终端确认与 Revise）、`wiki-agent view`（查看器的本地服务与 SSE）                                    | 间接    |
| `apps/viewer`         | React 查看器，只读（0015）                                                                                            | 否      |

- `packages/vault` 和 `packages/trajectory` 可以完全用普通单元测试覆盖，不需要 faux。
- `packages/trajectory` 不能依赖 Node 专有 API 之外的运行时；投影代码必须能在浏览器中运行，文件读写放在单独的 Node 入口。
- 测试用的小型 Vault 放在 `fixtures/vault/`。

## 工具链

沿用用户其他仓库的习惯：Node 24（`.nvmrc`）、pnpm 11、TypeScript、oxlint + oxfmt、Vitest、simple-git-hooks + lint-staged、查看器用 Playwright。Pi 依赖按 0002 锁定精确版本。

## 影响

- 新增依赖时要检查方向，例如 `packages/vault` 不能依赖 `packages/agent`。
- 查看器只通过 `packages/trajectory` 理解事件，不直接引用 `packages/agent` 的类型。
